<%= %> - Output Escaped Value

Outputs the value of a variable to HTML, escaping HTML characters.

<%= name %>

This outputs the value of name safely.

John Doe

<%- %> - Output Unescaped Value

Outputs raw HTML without escaping. Use carefully!

<%- htmlContent %>

This renders the HTML stored in htmlContent directly.

<strong>Bold Text</strong> → Bold Text

<% %> - Scriptlet / Logic Tag

Runs JavaScript code without outputting directly.

<% for (let i=0; i<3; i++) { %>
  <%= i %>
<% } %>

Loops from 0 to 2 and outputs each number.

012

<%_ %> - Whitespace Slurping

Removes whitespace before or after the tag in the output.

Hello<%_ if(true){ %>
World<%_ } %>

Output is “HelloWorld” without extra spaces.

HelloWorld

<%# %> - Comment

This tag is ignored and does not produce output.

<%# This is a comment %>

No output is produced for comments.

Logic Examples

Includes loops, conditionals, and partial includes.

Conditional

<% if (user.isAdmin) { %>
  Welcome Admin
<% } else { %>
  Welcome User
<% } %>
Welcome Admin
