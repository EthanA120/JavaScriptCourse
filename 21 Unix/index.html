Basic Navigation and File Management Commands (Bash)

	        
    
	            
  1. 
	                pwd (print working directory)
	                - Displays the full path of your current directory.
	                Example: pwd
	            
    2. 
	            
  2. 
	                ls (list)
	                - Lists files and directories in the current directory.
					Useful Options:
					
      
						
    • ls -l: Detailed list.
      • 
						
    • ls -a: Shows hidden files.
      • 
						
    • ls -la: Combination of both.
      • 
					
    
	                Example: ls -la
	            
    3. 
	            
  3. 
	                cd (change directory)
	                - Changes your current directory.
					Examples:
					
      
						
    • cd my_project: Go to a specific directory.
      • 
						
    • cd ..: Go up one directory.
      • 
						
    • cd ~: Go to home directory.
      • 
						
    • cd /c/Users/YourUser/Desktop: Go to an absolute path.
      • 
					
    
	            
    4. 
	            
  4. 
	                mkdir (make directory)
	                - Creates a new directory.
	                Example: mkdir new_folder
	            
    5. 
	            
  5. 
	                touch
	                - Creates a new, empty file..
	                Example: touch my_file.txt
	            
    6. 
	            
  6. 
	                rm (remove)
	                - Deletes files (permanently!).
	                
    Example: rm old_file.txt
    
									To delete a non-empty directory: rm -rf my_folder
									(use with caution!)
	            
    7. 
	            
  7. 
	                clear
	                - Clears the terminal screen.
	                Example: clear

Basic Git Commands

        
    
            
  1. 
                git config (configuration)
                - Sets your personal details for Git.
                Examples:
                
      
                    
    • git config --global user.name "Your Name"
      • 
                    
    • git config --global user.email "your.email@example.com"
      • 
                
    
            
    2. 
            
  2. 
                git init (initialize)
                - Creates a new Git repository in the current directory.
                Example: git init
            
    3. 
            
  3. 
                git clone
                - Copies an existing Git repository from a remote server.
                Example: git clone https://github.com/username/repository-name.git
            
    4. 
            
  4. 
                git status
                - Shows the current status of the repository.
                Example: git status
            
    5. 
            
  5. 
                git add
                - Adds changes to the staging area for the next commit.
                Examples:
                
      
                    
    • git add my_file.txt: Add a specific file.
      • 
                    
    • git add .: Add all changes.
      • 
                
    
            
    6. 
            
  6. 
                git commit
                - Creates a "snapshot" of the staged changes.
                Examples:
                
      
                    
    • git commit -m "Initial commit": Commit with a short message.
      • 
                    
    • git commit: Opens editor for detailed message.
      • 
                
    
            
    7. 
            
  7. 
                git log
                - Displays the commit history.
                Useful Options:
                
      
                    
    • git log --oneline: Shortened log.
      • 
                    
    • git log --graph --oneline --all: Graph view.
      • 
                
    
                Example: git log --oneline
            
    8. 
            
  8. 
                git branch
                - Manages branches.
                Examples:
                
      
                    
    • git branch: List branches.
      • 
                    
    • git branch new_feature: Create new branch.
      • 
                
    
            
    9. 
            
  9. 
                git switch (recommended over git checkout for switching)
                - Switches between branches.
                Examples:
                
      
                    
    • git switch new_feature: Switch to a branch.
      • 
                    
    • git switch -c another_feature: Create and switch.
      • 
                
    
            
    10. 
            
  10. 
                git merge
                - Merges changes from one branch into another.
                Example: git merge new_feature
            
    11. 
            
  11. 
                git remote
                - Manages connections to remote repositories.
                Examples:
                
      
                    
    • git remote -v: Show remotes.
      • 
                    
    • git remote add origin https://github.com/username/repo.git: Add a remote.
      • 
                
    
            
    12. 
            
  12. 
                git push
                - Uploads your local commits to the remote repository.
                Example: git push origin main
                
    First push of a new branch: git push -u origin new_feature
    
            
    13. 
            
  13. 
                git pull
                - Downloads changes from the remote repository and merges them locally.
                Example: git pull origin main

Example Basic Workflow

            
    
                
  1. 
                    Start a new project:
                    
    mkdir my_project - Creates a new directory.
    
                    
    cd my_project - Enters the new directory.
    
                    
    git init - Initializes a new Git repository.
    
                    
    touch README.md - Creates a README file.
    
                    
    git add . - Stages all files for commit.
    
                    
    git commit -m "Initial project setup" - Commits the staged files.
    
                
    2. 
                
  2. 
                    Work on a new feature:
                    
    git switch -c my_new_feature - Creates a new branch and switches to it (Make changes to files).
    
                    
    git status - Checks the status of the repository.
    
                    
    git add . - Stages the changes.
    
                    
    git commit -m "Added cool new feature" - Commits the changes with a message.
    
                    
    git push -u origin my_new_feature - Pushes the new branch to the remote repository.
    
                
    3. 
                
  3. 
                    Merge feature to main:
                    
    git switch main - Switches back to the main branch.
    
                    
    git pull origin main - Pulls the latest changes from the remote main branch.
    
                    
    git merge my_new_feature - Merges the feature branch into main.
    
                    
    git push origin main - Pushes the merged changes to the remote repository.
